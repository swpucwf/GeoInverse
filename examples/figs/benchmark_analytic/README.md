# 解析解对标案例 (benchmark_analytic)

## 案例概述

**物理场景**: 数值解与解析解对标验证——验证 FDEM 正演的数值精度。

**运行命令**: `python examples/benchmark_analytic.py`

---

## 图版说明

### fig_01_analytic_benchmark.png — 解析解对标
**表达内容**: 数值解与半空间解析解的对比。展示 Hz 二次场的实部/虚部，验证数值模拟的准确性。

**物理意义**: 通过对比均匀半空间模型的解析解和数值解，确认代码实现的正确性。误差应在可接受范围内（通常 < 1%）。
