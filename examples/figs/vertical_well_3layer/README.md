# 垂直井三层案例 (vertical_well_3layer)

## 案例概述

**物理场景**: 垂直井 LWD-FDEM 正演——仪器沿深度连续穿透扫描（2D 轴对称）。

**地层模型**:
- 上覆层: z < -4 m, σ = 0.20 S/m
- 储层: -4 ≤ z ≤ +4 m, σ = 0.01 S/m
- 基底: z > +4 m, σ = 0.50 S/m

**运行命令**: `python examples/vertical_well_3layer.py`

**表达内容**: 垂直井穿透三层地层的概念模型。展示井轴、源-接收器排列、地层界面及电导率值。

### v03_scan_geometry.png — 扫描几何示意图

### v04_forward_scan.png — 正演深度扫描响应
**表达内容**: 三个频率 (20/50/100 kHz) 下，Bz 二次场幅值随仪器深度的变化曲线。在层界面处可见明显的边界异常。

### v05_apparent.png — 视电阻率剖面
