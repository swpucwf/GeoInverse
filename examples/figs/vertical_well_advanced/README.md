# 垂直井进阶案例 (vertical_well_advanced)

## 案例概述

**物理场景**: 垂直井穿三层水平地层，2D 轴对称柱网格模拟。

**地层模型**:
- 上覆层 (overburden): z < -4 m, σ = 0.20 S/m
- 储层 (reservoir): -4 ≤ z ≤ +4 m, σ = 0.01 S/m  
- 基底 (basement): z > +4 m, σ = 0.50 S/m

**研究目的**: 演示源类型对比与反演正则化对比。

**运行命令**:
```bash
conda activate lwd
python examples/vertical_well_advanced.py
```

---

## 图版说明

### A_source_compare.png — 源类型对比

**表达内容**: 磁偶极子 (MagDipole) vs 有限回线 (CircularLoop) 的 2D 深度扫描响应对比。

**子图说明**:
- **(a) 磁偶极子(实线) vs 回线(虚线)**: 三个频率 (20/50/100 kHz) 下，两种源类型的 |Bz^s| 幅值随仪器深度变化曲线。实线为点偶极子，虚线为半径 0.5 m 的有限回线。
- **(b) 回线相对偶极子差异**: 回线响应相对于偶极子的百分比差异 (%)，展示有限尺寸线圈效应的深度依赖性。

**物理意义**: 在 2D 轴对称下，回线源可带轴向偏移（1D 层状模型不支持），因此能更真实地模拟实际线圈仪器。图中差异反映了线圈尺寸对高频浅部响应的影响。

**背景色带**: 黄/米/蓝色带分别对应上覆/储层/基底三层。

---

### B_inversion_compare.png — 反演正则化对比

**表达内容**: Occam 平滑反演 vs 稀疏块状反演的 2D 电阻率重建对比。

**子图说明**:
- **左图 (真实模型)**: 三层地层的真实 log10(σ) 分布，白色虚线标注层界面。
- **中图 (Occam 平滑回收)**: 传统 Tikhonov 正则化 (sparse=False) 的反演结果，界面过渡平滑。
- **右图 (稀疏块状回收)**: 稀疏正则化 (sparse=True, norms=[0,1,1]) 的反演结果，界面更尖锐，接近块状模型。

**物理意义**: 业务层子类封装修正了 `LWDFDEMInversion(sparse=True)` 的 BetaSchedule/UpdateIRLS 冲突 bug，使稀疏反演在 2D 场景下可正常运行。稀疏正则化更适合层状地层这种电阻率突变的模型。

**技术参数**:
- 频率: 20 kHz, 100 kHz
- 收发距: 1.0, 2.0, 3.0 m
- 数据噪声: 3% 相对误差
- 最大迭代: 5 次
